# Source history

Soundforge development began before a Git repository was created. On 29 August 2026, the surviving source folders were imported into Git chronologically to establish an honest paper trail.

## Preserved source snapshots

- `v0.1a`
- `v0.7a`
- `v0.8a.1`
- `v0.8a.2`
- `v0.8a.3`
- `v0.8a.4`
- `v0.8a.5`
- `v0.8a.6`
- `v0.9a.2` — current maintained source at the time Git was introduced

These commits contain the source present in the corresponding saved folders. Their commit dates match the snapshot dates. They do not claim to reproduce development activity between snapshots.

## Binary-only historical builds

Builds labelled `v0.8a.7`, `v0.8a.8`, `v0.8a.9`, and `v0.9a.1` survive as compiled release artifacts, but matching source snapshots were not found. They are therefore not represented by fabricated source commits or misleading tags. They may be preserved separately as GitHub Release attachments.

From `v0.9a.2` onward, normal Git commits and tags are the authoritative development history.
